# Eval 02 — Proposal data entry (niche high-competition, mode pemula)

## Task

Job posting Upwork (klien baru tanpa payment verified, diposting 3 jam lalu):

> "Need someone to clean up 2,000 rows of customer data in Excel — remove duplicates, standardize phone formats. Budget $40 fixed-price."

Seti BELUM punya review/klien di Upwork. Tuliskan proposal siap kirim memakai struktur skill + diferensiasi niche high-competition (B1b) + mode pemula jujur (B2b), lalu skor dengan rubrik skill.

Asumsi jujur tentang Seti (BOLEH dipakai): ia berlatih membersihkan dataset 5.000 baris (hapus duplikat, standarisasi format telepon +62, validasi email) dengan akurasi 99,8%; kecepatan ketik 65 WPM (tes 10fastfingers). TIDAK BOLEH mengarang pengalaman klien ("klien saya", "proyek-proyek saya").

## Verifier

LOLOS jika SEMUA terpenuhi, GAGAL jika satu saja gagal:

1. Panjang 150–250 kata; tidak ada slot `[SLOT]` yang tersisa.
2. Memuat angka kecepatan konkret (WPM / baris per hari) DAN janji turnaround spesifik (mis. 48 jam) yang masuk akal untuk 2.000 baris.
3. Menyebut tools spesifik (Excel, dsb.) — bukan "mahir komputer".
4. Bukti memakai mode pemula jujur: dataset latihan 5.000 baris / 99,8% — frasa "berpengalaman", "klien saya", "banyak proyek serupa" TIDAK BOLEH muncul.
5. Menawarkan sample kecil (mis. 50 baris pertama) sebagai bukti instan.
6. Keputusan memakai kriteria fase rintisan (B3b): boleh diambil karena budget kecil + scope jelas + selesai < 1 minggu — ditulis eksplisit.
7. Skor mandiri memakai rubrik skill: total ≥ 16 DAN dimensi kredibilitas bukti ≥ 3.

## Baseline

Tanpa skill: proposal pemula yang mengarang ("Saya berpengalaman mengerjakan banyak proyek data entry untuk klien") atau proposal pasrah tanpa diferensiasi yang tenggelam di antara 50 pelamar.
