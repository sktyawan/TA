# Eval 01 — Proposal dev (niche web app, klien terverifikasi)

## Task

Job posting Upwork (payment verified, diposting 2 hari lalu):

> "Need developer to build employee attendance dashboard, React + Supabase, budget $500 fixed-price."

Tuliskan proposal siap kirim untuk job ini memakai struktur skill (hook personalisasi → bukti relevan → rencana minggu pertama → CTA), lalu skor proposalmu sendiri dengan rubrik skor proposal di skill.

Asumsi jujur tentang Seti (BOLEH dipakai sebagai bukti): ia pernah membangun modul absensi + dashboard HR dengan React + Supabase untuk data 200+ karyawan, selesai dalam 3 minggu. TIDAK BOLEH mengarang nama klien atau pengalaman lain.

## Verifier

LOLOS jika SEMUA terpenuhi, GAGAL jika satu saja gagal:

1. Panjang 150–250 kata.
2. Dua kalimat pertama merujuk detail SPESIFIK posting (attendance dashboard + React + Supabase) — bukan sapaan generik.
3. Bukti: memakai pengalaman nyata yang diizinkan di atas (modul absensi, 200+ karyawan, 3 minggu) — tidak ada nama klien karangan, tidak ada klaim pengalaman tambahan.
4. Ada 2–3 bullet rencana konkret minggu pertama + tepat 1 CTA.
5. Checklist 4 kriteria keputusan (B3) ditulis dengan hasil lolos/gagal per item — keempatnya lolos.
6. Skor mandiri memakai rubrik skill: total ≥ 16 DAN tidak ada dimensi yang ≤ 2.

## Baseline

Tanpa skill: proposal generik ("Saya developer berpengalaman, saya bisa mengerjakan proyek Anda") tanpa personalisasi, tanpa angka, tanpa rencana, tanpa kriteria keputusan.
