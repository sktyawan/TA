# Contoh Proposal: Data Entry (niche high-competition, mode pemula)

**Input:** "Need someone to clean up 2,000 rows of customer data in Excel — remove duplicates, standardize phone formats. Budget $40 fixed. Posted 3 hours ago."

**Proses:**
1. Cek kriteria fase rintisan: skill match tinggi (Excel cleanup = kemampuan terukur Seti) ✓; klien baru tanpa payment verified TAPI budget $40 kecil + scope jelas + selesai < 1 minggu = boleh ✓; budget vs scope: 2.000 baris ≈ 4–6 jam kerja ≈ $7–10/jam efektif, masuk akal ✓; posting 3 jam ✓ → LAYAK, kirim SEKARANG (jangan tunggu).
2. Isi slot template dengan mode pemula jujur: bukti = proyek latihan 5.000 baris (jujur, terukur); diferensiasi high-competition: turnaround 48 jam + pertanyaan klarifikasi spesifik.

**Output (150 kata — sesuai format 150–250 kata):**
```
Halo,

Saya tertarik dengan proyek pembersihan 2.000 baris data pelanggan Anda — duplikat dan format telepon yang tidak standar memang masalah klasik yang membuat data tidak bisa dipakai untuk kampanye.

Walau saya baru di Upwork, saya berlatih dengan dataset 5.000 baris: hapus duplikat, standarisasi format telepon Indonesia (+62), validasi email — selesai dengan akurasi 99,8% dan kecepatan ketik 65 WPM (tes 10fastfingers).

Untuk proyek Anda, saya akan:
- Audit 2.000 baris memakai Excel: identifikasi duplikat berdasar kombinasi nama + telepon dan petakan pola format yang rusak
- Bersihkan dan standarisasi seluruhnya, lalu serahkan file Excel rapi plus 1 halaman ringkasan perubahan

Sebagai bukti kualitas, saya kerjakan 50 baris pertama sebagai contoh — gratis, tanpa komitmen. Satu pertanyaan: apakah format telepon yang diinginkan +62 semua, atau ada format khusus yang harus saya ikuti?

Saya bisa mulai hari ini dan selesai dalam 48 jam — $40 fixed-price, 1 milestone. Terima kasih,
Seti
```
Checklist keputusan: 4/4 lolos (mode rintisan). Rekomendasi: kirim dalam 1 jam ini.

**Skor mandiri (rubrik):** hook 5/5 (rujuk 2.000 baris + duplikat + format telepon dari posting), bukti 5/5 (dataset latihan 5.000 baris + 99,8% + 65 WPM, jujur), rencana 5/5 (2 langkah konkret minggu ini), format 5/5 (150 kata, struktur lengkap, 1 CTA) = **20/20** → boleh kirim.
