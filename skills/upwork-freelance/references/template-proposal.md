# Template Proposal & Cold Email per Niche

Slot ditandai `[SLOT]` dan WAJIB diisi sebelum kirim. Tidak boleh ada slot tersisa di output final.

## Template umum (150–250 kata)

```
Halo [NAMA_KLIEN],

Saya tertarik dengan [DETAIL_SPESIFIK_DARI_POSTING]. [KALIMAT_HUBUNGAN_DENGAN_PENGALAMAN].

Baru-baru ini saya [CONTOH_KERJA_MIRIP] yang menghasilkan [HASIL_TERUKUR].

Untuk proyek Anda, saya akan:
- [LANGKAH_1_MINGGU_PERTAMA]
- [LANGKAH_2_MINGGU_PERTAMA]

[PERTANYAAN_KLARIFIKASI_SATU_KALIMAT]?

Saya bisa mulai [KETERSEDIAAN]. Terima kasih,
Seti
```

## Niche high-competition: data entry, VA, transkripsi

Niche ini dapat 30–80 pelamar per job — hook standar saja tidak cukup. Tambahkan ke proposal:

- **Angka kecepatan konkret:** "ketik 65 WPM", "mampu memproses ±1.000 baris data terstruktur per hari dengan akurasi 99%+". Angka mengalahkan klaim.
- **Janji turnaround spesifik:** "file 500 baris selesai dalam 24 jam" — hanya janji yang benar-benar bisa dipenuhi.
- **Tools spesifik:** Excel/Google Sheets, OCR, regex cleanup, dsb. Bukan "mahir komputer".
- **Tawaran sample kecil:** "Saya kerjakan 50 baris pertama sebagai contoh kualitas — gratis, tanpa komitmen." Bukti instan ini mengalahkan 90% pelamar yang hanya berjanji.
- **Kecepatan kirim:** kirim proposal dalam 1–2 jam pertama setelah posting. Di niche kompetitif, job berumur > 48 jam praktis sudah dimenangkan orang lain (aturan < 7 hari tidak berlaku di sini).

## Niche dev / no-code

- Rujuk stack persis dari posting (mis. "React + Supabase") di 2 kalimat pertama — jangan generalisasi jadi "web development".
- Bukti: satu proyek paling mirip + angka (skala data/user, waktu pengerjaan). Screenshot/demo link mengalahkan paragraf.
- Rencana minggu pertama: setup teknis konkret (skema DB, auth, dsb.), bukan "saya akan pelajari kebutuhan Anda".

## Niche desain grafis

- Bukti: 1–2 item portfolio paling mirip gaya yang diminta + hasil terukur bila ada (mis. "CTR naik 18% setelah ganti thumbnail").
- Tawarkan 1 konsep sketsa/mockup gratis sebagai sample — bukan "revisi unlimited".

## Mengisi slot bukti jika belum punya klien (mode pemula)

Jangan pernah mengarang pengalaman — isi CONTOH_KERJA_MIRIP / HASIL_TERUKUR dengan salah satu yang JUJUR dan terukur:

- **Proyek latihan terukur:** "Saya membersihkan dataset latihan 5.000 baris (hapus duplikat, standarisasi format tanggal/telepon, validasi email) dengan akurasi 99,8% — file contohnya siap saya tunjukkan." Tulis angkanya, bukan klaimnya.
- **Metrik kemampuan:** kecepatan ketik (tes di keybr.com / 10fastfingers, sebut WPM), skor tes skill Upwork, atau sertifikasi relevan (misal: Google Data Analytics, Microsoft Excel Expert).
- **Sample gratis:** tawarkan 15–30 menit kerja contoh. Biarkan kualitas yang bicara menggantikan riwayat klien.
- Frasa yang dilarang di mode ini: "berpengalaman", "telah mengerjakan banyak proyek serupa", "klien saya" — semua itu bohong jika belum ada klien.

## Cold email (di luar Upwork)

- Subjek: spesifik, bukan "Jasa Freelance". Contoh: "Ide perbaikan dashboard HR [NamaPerusahaan]".
- Isi: 3 paragraf pendek — observasi spesifik tentang bisnis mereka, satu bukti hasil, satu CTA ringan (bukan "kapan meeting?", tapi "boleh saya kirim 1 contoh mockup gratis?").
- Follow-up 1x setelah 5–7 hari. Tidak ada respons setelah itu = berhenti, jangan spam.
