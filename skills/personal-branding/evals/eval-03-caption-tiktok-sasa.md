## Task

Tulis caption TikTok untuk video: Sasa GRWM (get ready with me) sebelum nongkrong bareng teman, outfit kasual, suasana ceria. Panjang maksimal 150 karakter (termasuk hashtag). Output: caption final + 3 hashtag.

## Verifier

Caption dinyatakan LOLOS bila memuat SEMUA kriteria berikut:

- [ ] **Suara Sasa**: hangat, relatable, playful/sedikit sassy — kayak ngobrol sama sahabat; boleh pakai catchphrase "Fix banget." / "Kamu juga kan?".
- [ ] **Hook di awal**: kalimat pertama membuat orang berhenti scroll (pertanyaan relatable atau klaim playful), bukan pembuka datar ("Halo guys, ini video GRWM saya").
- [ ] **Panjang ≤150 karakter** termasuk hashtag.
- [ ] **3 hashtag relevan**: campuran hashtag persona/niche (#sasaberlian, #grwm, dsb) — bukan hashtag developer (#coding, #programming).
- [ ] **Tidak ada klaim palsu atau hard-sell GAS**: tidak ada ajakan download, tidak mengarang fakta.

Caption dinyatakan GAGAL bila nadanya formal/korporat, tidak ada hook, atau memakai hashtag developer.

## Baseline

Output tanpa skill: "GRWM sebelum nongkrong! Outfit kasual hari ini. #grwm #ootd #daily" — datar, tidak ada suara Sasa, tidak ada hook.
