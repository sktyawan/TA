## Task

Tulis postingan Facebook teks-native (tanpa video/foto) untuk mengumumkan live Sasa hari Jumat malam jam 19.00 WIB bertema "curhat santai + Q&A soal quarter-life crisis". Postingan harus berdiri sendiri tanpa bergantung pada visual.

## Verifier

- [ ] Hook di kalimat pertama (bukan pengumuman kering "jangan lupa nonton live")
- [ ] Format teks-native: bisa dipahami penuh tanpa gambar/video; paragraf pendek (maks 3 baris layar ponsel)
- [ ] Panjang 80–200 kata (bukan pengumuman 1 baris, bukan esai)
- [ ] Tepat 1 CTA diskusi (1 kalimat tanya) — mis. mengajak audiens menitipkan pertanyaan untuk live
- [ ] Maksimal 2 emoji, di akhir kalimat
- [ ] Info praktis lengkap: hari, jam WIB, tema live — tanpa link eksternal di badan caption
- [ ] Suara Sasa: hangat, relatable, playful

Lolos jika semua kotak tercentang. Gagal jika satu saja tidak terpenuhi.

## Baseline

Tanpa skill: "Jangan lupa nonton live Jumat ya guys 🙏🙏🙏 #live #sasa" — 9 kata, tanpa hook, tanpa info jam/tema, emoji berlebih.
